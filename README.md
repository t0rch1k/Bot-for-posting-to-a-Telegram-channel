# **Telegram PostBot**

Бот для создания, предпросмотра, отложенной публикации и моментального постинга сообщений в Telegram-канал. Поддерживает:

* Заголовок + текст
* Хештеги (опционально)
* Кнопки (до нескольких)
* Медиа (фото, видео, гиф)
* Отложенную отправку по времени
* Удаление медиа после публикации

# **Возможности**


* Поддержка отложенных публикаций
* Множественные кнопки с названиями и URL
* Поддержка одного медиафайла (удаляется после отправки)
* FSM (машина состояний) для поэтапного диалога
* Проверка ссылок и корректности ввода

# **Очистка временных файлов**

Все медиа после отправки автоматически удаляются из папки /media, так что сервер не захламляется.

# **Требования**

* Python 3.10+
* Библиотека aiogram>=3.20.0
* Запуск от имени пользователя, у которого есть доступ к папке media/ и правам на запись
